DREAM / ULTRON

Two names in the source material.

The original website refers to the Dream intelligent high-tech robot, while the whitepaper also uses the name Ultron in several places. Both names are associated with the AI trading system. This website makes the inconsistent naming visible rather than inventing an unsupported technical distinction.

The materials describe neural networks, real-time market data, natural-language processing, scenario analysis and modular interfaces as technical goals. The source website reviewed for this edition does not link to concrete performance metrics, public model cards or independent technical audit reports.
